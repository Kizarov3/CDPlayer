# BLIP (deck pet) v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dot-matrix pet in the deck's display that grows from listening, reacts to the music and to you — v1 of the design.

**Architecture:** A pure main-process module (`pet.js`) turns listening history into the pet's stage, form, items and
events; `main.js` keeps its small state in `pet.json` and answers over IPC (`pet:get`, `pet:set`, and the pet's part of
`plays:add`'s reply). The renderer draws it: a pure sprite module (`pet-sprite.js`, the mock's script made importable)
and a view (`pet-view.js`) that owns the canvas in `#deck-display`, the reactions, its words and its card. TERMINAL
gets the same bitmap in half-blocks through `tui.js`.

**Tech Stack:** Electron, plain ES modules in the renderer, CommonJS in main, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-17-deck-pet-design.md` (mock: `…/2026-11-17-deck-pet-mock/index.html`)

## Global Constraints

- Off by default; setting = `settings.txt` line 34 (index 33), `1`/`0`, key `pet`.
- Grid 25×16, body box 16×14 at column 5, row 2; ~2.6 px pitch in the deck; ≤ 8 fps; drawn only while visible and
  playing; still pose with animations off / reduced motion.
- Name default `BLIP`, ≤ 8 chars, upper case, shown only on the card.
- Hatch: first album played through **or** 1 h listened, counted from when it was turned on. KID 10 h, TEEN 30 h,
  ADULT ≥ 50 h and ≥ 30 days since hatching, at a monthly reading (month key `YYYY-MM` differs from `lastMolt`).
- Habit forms (from the last 30 days, first match): NIGHT OWL ≥ 40 % plays 23:00–04:00 → EARLY BIRD ≥ 40 % 05:00–09:00
  → LOYALIST one artist ≥ 40 % → EXPLORER ≥ 50 first plays → RAVER ≥ 25 artists → COLLECTOR (otherwise).
- Surprises v1: GHOST (a hidden track found), ECHO (a play on the same month/day as a play of the same song exactly a
  year before).
- Items v1: CROWN 10 albums through · GOLD RECORD one album through 5× · HEADPHONES 100 h · SCARF 7 different days ·
  PARTY HAT worn by itself on the hatch-day anniversary.
- Words only in silence (between tracks / paused), ≥ 5 tracks apart, ~2.3 s, in place of the flags.
- Never: hunger, death, streaks, notifications, sounds, counters on the display, words about time away.
- Hours = Σ plays × the song's length (unknown length: 240 s).
- No AI attribution lines in commits (user rule).
- Tests set `CDPLAYER_HOME` to a temp dir before requiring `store`.

## Review Focus

- A user with years of imported history turning it on: must start as an EGG, hatch on the next album/hour, then
  jump straight to TEEN at most (not ADULT) — `pet.test.js` "imported history".
- Turned off then on again: state kept (no new egg) — `pet.test.js` "parse round-trip".
- Narrow window / CD VIEW: the pet hides rather than pushing TOTAL off — CSS container query, checked by eye.
- A play of a song not on the shelf (a stream, an audio CD): counts as a snack, no crash on album lookups —
  `pet.test.js` "unknown album".
- Corrupt or missing `pet.json`: a fresh pet, no throw — `pet.test.js` "parse garbage".

### Task 1: `pet.js` — the pet from the history (main, pure)

**Files:** Create `src/main/pet.js`, `test/pet.test.js`.

**Interfaces — Produces:**
- `empty(now, random = Math.random) → Pet` = `{ version: 1, name: 'BLIP', since: now, hatchedAt: null, hatchAlbum: null, stage: 'egg', form: null, chosen: null, found: {}, items: {}, worn: null, temper: one of TEMPERS, lastMolt: null }`
- `parse(text, now) → Pet` (garbage → `empty(now)`), `format(pet) → string` (JSON).
- `TEMPERS = ['sleepy','bouncy','curious','shy']`, `HABITS = ['owl','bird','loyalist','explorer','raver','collector']`.
- `stats({ list, seconds, through, albumOf, firsts, since, now }) → Stats` where `list` = `[[ms, path]]` oldest first,
  `seconds(path) → s|0`, `through` = album-runs' `{ [id]: { n, last } }`, `albumOf(path) → { id, title, artist } | null`,
  `firsts` = Map path → first-play ms. `Stats` = `{ hours, hoursSince (plays at/after since), throughSince (albums
  through with last ≥ since), albums (Σ n), maxOne, favourite: { id, title } | null, days, month: { plays, night,
  morning, topShare, artists, firsts } }`.
- `habitForm(month) → one of HABITS`.
- `evolve(pet, stats, now, { hidden = false, echo = false } = {}) → { pet, events }`; events are `{ kind: 'hatch'|'grow'|'molt'|'item'|'found', … }` (`grow: { stage }`, `molt: { from, to }`, `item: { item }`, `found: { form }`). Pure: returns a new object.
- `shown(pet, now) → { stage, form, item }` — the form to draw (`chosen ?? form` when adult, else the stage) and the item (`party` on the hatch anniversary, else `worn`).
- `isEcho(list, path, now) → boolean`.
